# Certificate PDF font

One unmodified Noto Sans Devanagari variable TrueType font, covering Latin,
Latin-ext and Devanagari. The server embeds it with `subset: true`.

Source: Google Fonts revision `2bc5d431b584d89e646214bf6cfa75494e76ceea`,
[`ofl/notosansdevanagari`](https://github.com/google/fonts/tree/2bc5d431b584d89e646214bf6cfa75494e76ceea/ofl/notosansdevanagari).
Upstream filename: `NotoSansDevanagari[wdth,wght].ttf`.
